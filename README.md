# Woody's Burgers

Sitio web estático (HTML + CSS + JS, sin dependencias). Abre `index.html` en el navegador o publícalo con GitHub Pages.

- `index.html` – página
- `styles.css` – estilos
- `main.js` – enlaces de WhatsApp (pedido / cotizar evento) y pestañas del menú
- `assets/` – logo, menú impreso y fotos
